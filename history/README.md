# Migration archive

`python-widget-before-monorepo-20260828.bundle` is a complete, verified Git
bundle from the former standalone Python-widget repository. It includes its
prior branches and the `codex/archive-python-widget-before-monorepo-20260828`
snapshot, which captured the uncommitted working tree before this monorepo
migration.

To inspect it independently, clone the bundle into a new directory:

```powershell
git clone python-widget-before-monorepo-20260828.bundle restored-python-widget
```
